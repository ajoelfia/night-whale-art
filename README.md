A deterministic Python program that draws "The Night Whale": a galaxy-filled whale swimming across a dusk sky, raining tiny stars onto a quiet sea while one small lighthouse watches. It renders a 1024x1024 PNG using only the Python standard library — no network, no randomness, the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
